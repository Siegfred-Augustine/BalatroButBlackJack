## Branch Description

This current branch utilitized git command such as 

```
git pull
git add
git commit
git push
git revert
```

### Tools Used

+ **git pull** was first used to pull the latest version of the branch to the local machine
+ **git add** was used to add and stage the changes for the first version commit of the updated *Readme file*
+ **git commit** was used to store and save the changes locally.
+ **git push** was used to upload the changes to the Github repository.
+ **git revert** was used to restore the changes made since the last commit.
